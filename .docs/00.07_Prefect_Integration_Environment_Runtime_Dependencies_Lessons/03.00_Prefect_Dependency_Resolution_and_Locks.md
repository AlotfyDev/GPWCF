# 03 — Prefect Dependency Resolution and Locks

## 1. Objective

Explain how Prefect and its transitive runtime closure were resolved, pinned and represented as offline lock profiles, while distinguishing the dependency bundle's operational locks from the formal release gate.

## 2. Direct declaration

The package metadata pins the optional integration dependency:

[project.optional-dependencies]
prefect = ["prefect==3.9.2"]

The dependency bundle target is Windows AMD64 / CPython 3.15.1. This target matters because some transitive dependencies publish ABI/platform-specific wheels.

## 3. Resolver approach

The Prefect closure was resolved from the declared Prefect 3.9.2 requirement for the target runtime/platform using pip's dry-run resolution report with installed packages ignored. The generated resolver report was then transformed into a hash-locked requirements file. The prior managed qualification environment snapshot of 106 packages was explicitly not copied as the new runtime lock.

The resolver report and generated lock represent 105 distributions for the Prefect runtime profile.

## 4. Lock profiles

| File | Purpose | Package scope |
|---|---|---|
| locks/prefect-runtime.lock | Optional Prefect integration runtime | Prefect 3.9.2 plus resolved mandatory dependency closure; 105 distributions |
| locks/pytest-dev.lock | Test runner | pytest 9.2.0 and its dependency closure |
| locks/build-backend.lock | Build backend | setuptools 84.2.1 |

The installer combines profiles as follows:
- prefect: Prefect runtime lock;
- test: pytest lock;
- build: build backend lock;
- development: Prefect runtime plus pytest;
- all: Prefect runtime, pytest and build backend.

The environment factory supports prefect, development and all. The lower-level installer supports all five profiles.

## 5. Hash enforcement and offline behavior

Each lock contains exact versions and SHA-256 hashes. The installer uses:
- --no-index;
- --only-binary=:all:;
- --find-links pointing to the local wheelhouse;
- --require-hashes.

This prevents the installer from silently resolving newer versions from an index or building a source distribution during normal installation.

The manifest records the wheelhouse artifact filenames and SHA-256 hashes. Verify-GpwcfBundle.ps1 checks those hashes and checks that the Core dependency list is empty and Prefect remains the optional extra.

## 6. Important release-gate distinction

The existing PREFECT-LOCK-RELEASE-GATE.md defines a stricter release process: reconstruct the lock from a clean environment installing gpwcf[prefect], review runtime relevance, record hashes/platform markers, and complete package-by-package license review before release.

The current operational bundle has a hash-locked Prefect closure, offline installation evidence and a 105-distribution resolver report. However, that does not by itself prove every formal release-gate requirement has been signed off. In particular:
- package-by-package license review remains pending;
- the release-gate document still needs reconciliation with the current bundle process and evidence;
- the clean reconstruction provenance required by that gate must be explicitly reviewed and accepted;
- the exact relationship between the bundle lock and the distributable extra must be retained as a release artifact.

Do not mark the formal release gate passed solely because offline installation works.

## 7. License metadata

The manifest stores available license/license-expression metadata for resolved packages. Some distributions do not expose license metadata in the resolver report. Metadata presence is not legal review, and missing metadata is not permission to infer a license. The review remains pending.

## 8. Lessons

- Do not freeze a developer environment: it may contain unrelated packages.
- Resolve from the direct declared requirement in a clean target context.
- Pin exact versions and hashes to make offline installation deterministic.
- Keep runtime, test and build profiles distinct.
- Treat a technically usable lock and an approved release lock as separate states.
