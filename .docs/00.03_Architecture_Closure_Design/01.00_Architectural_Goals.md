Each entity holds its own responsibilities, while composition facilitates functional linkage between them; meanwhile, Prefect executes the native workflow hierarchy.

There are four conditions that no process may violate:

1. Functional Completeness: Every function must have a clear contract, implementation, result, and a defined lifecycle responsibility.
2. Hierarchical Completeness: Each level must be able to participate in hierarchical nesting within its own scope, without requiring the creation of a custom workflow engine inside GPWCF.
3. Dependency Integrity: There must be no reverse or circular dependencies between components.
4. Runtime Independence: The core must remain usable without requiring the installation of Prefect, while allowing for the use of Prefect integration whenever necessary.
